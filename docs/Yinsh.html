(static) valid_move(game_state, original_position, new_position) → {true|undefined}

Description:

  • Checks if move is a legal Yinsh move. A move is legal if:

    • the game state is active
    • the new position is unnocupied by rings and markeres,
    • the position is on the hex-board
    • it travels in a straight line
    • it doesn't pass through a ring -it lands immediately after the last consecutive marker
